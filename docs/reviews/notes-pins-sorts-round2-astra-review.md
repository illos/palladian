2. **R2-2 — should fix: newer acknowledgements resurrect older edits.** [App.tsx:347](/srv/presidium/projects/palladian/code/.worktrees/pins-sorts/apps/notes/src/App.tsx:347) removes matching edits independently. Moreover, the timeout starts only after `save` resolves ([line 798](/srv/presidium/projects/palladian/code/.worktrees/pins-sorts/apps/notes/src/App.tsx:798)); an unresolved write remains indefinitely. **Fix:** retire superseded edits per affected field when acknowledging newer changes, and start the intended expiry at enqueue time. Test rapid reversals and coalesced snapshots.

3. **R2-3 — should fix: `mine` still exceeds transaction limits at supported quotas.** [arrangement.ts:117](/srv/presidium/projects/palladian/code/.worktrees/pins-sorts/apps/notes-backend/convex/arrangement.ts:117) combines per-note access checks with notebook inventory reads. Convex counts both `db.get` and `db.query` toward its [4,096-range limit](https://docs.convex.dev/production/state/limits#transactions).

4. **R2-4 — should fix: duplicate batch entries corrupt position uniqueness.** [arrangement.ts:233](/srv/presidium/projects/palladian/code/.worktrees/pins-sorts/apps/notes-backend/convex/arrangement.ts:233) resolves every existing row before inserting anything. Sending the same previously unpositioned note twice creates two rows; subsequent updates fail at `.unique()`. Reproduced through the public mutation. **Fix:** reject duplicate `noteId`s before validation/quota accounting and repair any existing duplicates.

5. **R2-5 — should fix: truncated inventory deletes valid orders.** [arrangement.ts:73](/srv/presidium/projects/palladian/code/.worktrees/pins-sorts/apps/notes-backend/convex/arrangement.ts:73) discards `notebookInventory.complete`, then [line 200](/srv/presidium/projects/palladian/code/.worktrees/pins-sorts/apps/notes-backend/convex/arrangement.ts:200) treats absence as lost access. A reproduction saved an order for an owned notebook beyond the inventory cutoff: `mine` hid it, and quota reclamation deleted it. **Fix:** verify access directly for referenced notebooks; never infer inaccessibility from an incomplete inventory.

6. **R2-6 — should fix: unusable positions can permanently hold the quota.** [arrangement.ts:64](/srv/presidium/projects/palladian/code/.worktrees/pins-sorts/apps/notes-backend/convex/arrangement.ts:64) considers a position live when its note remains readable, even without notebook access. `mine` hides those positions, and `setPositions` cannot update them, but reclamation retains them. A limits-enabled reproduction with 1,000 individually shared notes returned zero positions and rejected positioning an owned note. **Fix:** reclaim positions whose notebook is inaccessible, using bounded, direct notebook-access checks.

The arrangement cleanup change does not establish complete retention safety.
