# Notes first release — core implementation evidence

Date: 2026-10-15. Scope: delivery plan slice 1 and the backend half of slice 3 in [07 — Delivery plan](../specs/notes-app/07-delivery-plan.md), under owner decisions D91–D94. Branch `feat/notes-core`. Independent review is recorded separately.

## Result

The cached-first app now has a server. Notes, notebooks and sharing live in Convex; every read, search, edit, history and agent path goes through one authorization module. Open notes edit collaboratively; the library and note text mirror into the existing device cache so launch still needs no network.

| Area                                                  | Implementation                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## Known limits and pending work

- Invitation and password-reset email need a Cloudflare Email Service sender domain (an owner DNS decision); invitations use copyable links meanwhile, and password reset is not yet available.
- Agent claims with human cancellation, collections, location, file attachments on R2, and history browsing UI are not implemented yet.
- Physical iPhone 15 Plus and Safari/WebKit checks were not performed; WebKit cannot launch on this host. Chromium mobile emulation is not iPhone evidence.
- Background text caching fetches notes one query at a time (three concurrent); very large first syncs take time but stay off the interaction path.
- Restoring a revision replaces the document in one step; collaborators' unsent edits inside the restored range are mapped to its edges.

| Finding                                   | Fix                                                                                                                                                                                                                                                                                                                                                              | Evidence                                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R4-2 — quote and list formatting rejected | `applySafeStep` structurally checks the range the step changed in the applied result: every overlapping node, recursively, and its ancestors' content. Open slices and wrapping gaps are completed by the step, so checking the slice alone rejected valid edits. Shipped as a production hotfix (`8a9c87f`)                                                     | Unit test runs the editor's real commands (quote, lift, block types, list wrap/split/sink/lift, task items, marks, split, join) through `applySafeStep`; fails on `ddd178b`. | R4-1 — broad recovery diffs erased edits  | Inline units are whole code points with UTF-16 sizes. A Myers diff (cost grows with the number of differences, up to 2,000 edits per sequence) replaces the size-capped LCS. Changed blocks are paired by kind, and type changes become content-preserving markup steps. With no exact piecewise diff, `diffSteps` returns null and recovery keeps both versions | Core tests: emoji, a 2,100-character paragraph, a type change plus an inserted block, each rebased over a collaborator's edit, which survives; 300 random multi-block edits reproduced exactly. Keeping both versions (`splitConflict`) happens in one IndexedDB transaction, and only if the draft is still exactly the snapshot that was compared. The note takes the server's current version. The local content becomes a new local draft in the same notebook, which the same sync creates as a separate note. Nothing is rebased as a broad replacement.
