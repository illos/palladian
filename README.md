# Palladian

A personal platform for small agent-built web apps, with shared identity, navigation, theme, data services, files, and search.

This workspace currently contains the implementation specification and handoff only. No application has been built or deployed.

- [Product and architecture specification](docs/specs/palladian-platform-v1.md)
- [Phased execution plan and acceptance tests](docs/handoff/execution-plan.md)
- [Ready-to-use implementation and review prompts](docs/handoff/IMPLEMENTER-PROMPT.md)

Start with P0. Use independent review checkpoints before building on core auth, authorization, persistence, and integration changes. The older Deltos migration plan is reference material, not this project's execution plan.
